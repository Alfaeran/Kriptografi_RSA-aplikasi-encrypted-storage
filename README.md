# Kriptografi RSA - Aplikasi Encrypted Storage

Repository ini berisi program UI dengan 2 studi kasus algoritma kriptografi:

1. **Studi Kasus 1**: Caesar Cipher (enkripsi/dekripsi teks)
2. **Studi Kasus 2**: **Implementasi RSA** (generate key, enkripsi, dekripsi)

## Kebutuhan tugas yang dipenuhi

- Tugas dikerjakan berkelompok dengan validasi **3 anggota** pada UI.
- Program memiliki **2 studi kasus kriptografi berbeda**.
- Studi Kasus 2 mengimplementasikan **algoritma RSA**.
- Program menggunakan **User Interface (UI)** agar bisa diinteraksikan pengguna.
